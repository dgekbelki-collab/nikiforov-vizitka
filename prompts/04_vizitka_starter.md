# Промт: стартовая визитка (шаблон)

**Дата:** 2026-05-10
**Назначение:** Базовый промт-шаблон для генерации персональной визитки. Использовался как отправная точка перед итерациями (v1 → v2 → v3) текущего [vizitka.html](../vizitka.html).

---

Создай интерактивный файл `vizitka.html` — персональную визитку.

**Данные:**
- Имя: `{Ваше имя и фамилия}`
- Специализация: `{Чем вы занимаетесь}`
- Telegram: `{ссылка на ваш ТГ}`

**Дизайн:**
- Тёмный фон (`#0a0a0a`)
- Имя крупно, с градиентным свечением
- Социальные сети — иконки с hover-эффектом
- Кнопка «Написать мне» с анимацией
- Красиво и на компьютере, и на телефоне

Всё в одном HTML-файле, без внешних зависимостей. Для иконок используй SVG.
