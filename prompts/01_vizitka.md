# Личная визитка — Никифоров Евгений

**Цель:** одностраничная цифровая визитка вейбкодера. Открывается с телефона и десктопа, делится одной ссылкой.

**Контекст:** первый продукт в проекте `Nikiforov_Evgeny`. Аналог по структуре — визитка Елены Поповой ([Documents/my-frist-projekt/Elena_Popova/vizitka.html](../../my-frist-projekt/Elena_Popova/vizitka.html)), но в более «техно/неоновой» стилистике под IT-роль.

**Данные:**
- Имя: Никифоров Евгений Николаевич
- Специализация: вейбкодер
- Telegram: @evgeny_nikiforov
- Email: dgekbelki@gmail.com

**Задача:**
- Один HTML-файл `vizitka.html`, без внешних зависимостей.
- Тёмный фон `#0a0a0a`, имя крупно с градиентным свечением.
- Иконки соцсетей (SVG) с hover-эффектом.
- Кнопка «Написать мне» с анимацией → ведёт в Telegram.
- Адаптив под мобильный.

**Ограничения / стиль:**
- Все стили inline в `<style>`, иконки — inline SVG.
- Уважать `prefers-reduced-motion`.

**Критерий готовности:**
- Открывается двойным кликом из проводника, без сборки.
- На мобильном (≤480px) ничего не уезжает за край.
- Hover работает на десктопе, тач-таргеты ≥44×44 на мобильном.
